# Atmos QoL Pack

Модпак без собственного кода: в нём только зависимости, поэтому установка с Mod Portal скачивает и включает весь набор. Требует Space Age (quality, elevated rails, recycler).

| Мод | Назначение |
| --- | --- |
| Atmos Auto Heal, Atmos Auto Fire, Atmos Enemy Range Visualizer, Atmos Shotgun Tiers, Atmos Machine Tiers, Atmos Faster Start | Моды Atmos |
| autobuild_fork, CursorEnhancements, FilterHelper, Fill4Me, Shortcuts-ick, squeak-through-2, VehicleSnap, pump | Удобство строительства и управления |
| helmod, RateCalculator, BottleneckLite, Milestones | Планирование и статистика |
| gun-range-visualizer, bullet-trails, DiscoScience | Визуал |
| hextorio, RPGsystem, more-achievements | Геймплей |
| flib | Библиотека |

Несовместим с оригинальным `faster-start` (его заменяет Atmos Faster Start).

Список зависимостей повторяет текущую игру автора; обновляйте его при изменении набора.

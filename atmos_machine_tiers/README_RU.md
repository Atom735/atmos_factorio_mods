# Atmos Machine Tiers

Тиры для производственных машин, по аналогии с Atmos Shotgun Tiers.

- Охватывает все здания типа **assembling-machine** (сборочные автоматы, химзавод, нефтепереработка, центрифуга, машины Space Age и модов), **furnace**, **mining-drill** (буры, большой бур, нефтекачалка) и **морские насосы**; **лаборатории** — опционально.
- Тир N+1 крафтится из **5** машин тира N (количество настраивается). Рецепты открываются вместе с базовой машиной.
- По умолчанию за тир: **+100% скорости**, **+1 слот модуля**, **+100% потребления энергии** (загрязнение растёт вместе с энергией). Тир 2 = 2× скорость, тир 5 = 5×.
- Машины сохраняют оригинальную графику; в правом верхнем углу рисуется цифра тира (★ для мастер-тира). У иконок предметов тот же значок.
- Тиры образуют цепочку улучшений: работают планировщик улучшений и быстрая замена.

## Настройки

| Настройка | По умолчанию |
| --- | --- |
| Количество тиров | 5 |
| Машин предыдущего тира на улучшение | 5 |
| Рост бонусов | линейно / сложно |
| Бонус скорости за тир | 100% |
| Рост потребления энергии за тир | 100% |
| Доп. слоты модулей за тир | 1 |
| Загрязнение растёт вместе с энергией | вкл |
| Сборщики / печи / буры / морские насосы / лаборатории | вкл / вкл / вкл / вкл / выкл |
| Исключённые машины (через запятую) | пусто |
| Значок тира: показ / размер / только alt (карта, runtime) | вкл / 0.6 / выкл |

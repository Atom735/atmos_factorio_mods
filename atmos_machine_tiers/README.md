# Atmos Machine Tiers

Upgrade tiers for production machines, in the spirit of Atmos Shotgun Tiers.

- Covers every **assembling-machine** (assemblers, chemical plant, oil refinery, centrifuge, Space Age machines, modded ones), **furnace**, **mining-drill** (mining drills, big mining drill, pumpjack) and **offshore pumps**; **labs** optionally.
- Tier N+1 is crafted from **5** machines of tier N (count configurable). Recipes unlock together with the base machine.
- Defaults per tier: **+100% speed**, **+1 module slot**, **+100% energy use** (pollution scales with energy). Tier 2 = 2× speed, tier 5 = 5× speed.
- Machines keep their original graphics; a tier digit (★ for the master tier) is drawn in the top-right corner. Item icons get the same badge.
- Tiers form an upgrade chain, so the upgrade planner and fast-replace work.

## Settings

| Setting | Default |
| --- | --- |
| Number of tiers | 5 |
| Previous tier machines per upgrade | 5 |
| Bonus scaling | linear / compound |
| Speed bonus per tier | 100% |
| Energy use increase per tier | 100% |
| Extra module slots per tier | 1 |
| Scale pollution with energy | on |
| Assemblers / furnaces / mining drills / offshore pumps / labs | on / on / on / on / off |
| Excluded machines (comma list) | empty |
| Tier badge: show / size / alt mode only (map, runtime) | on / 0.6 / off |

# Atmos Machine Tiers

Тиры для производственных машин, по аналогии с Atmos Shotgun Tiers.

- Охватывает все здания типа **assembling-machine** (сборочные автоматы, химзавод, нефтепереработка, центрифуга, машины Space Age и модов), **furnace**, **mining-drill** (буры, большой бур, нефтекачалка) и **морские насосы**; **лаборатории** — опционально.
- Тир N+1 крафтится из **5** машин тира N (количество настраивается). Рецепты открываются вместе с базовой машиной.
- По умолчанию за тир: **+100% скорости**, **+1 слот модуля**, **+100% потребления энергии** (загрязнение растёт вместе с энергией). Тир 2 = 2× скорость, тир 5 = 5×.
- Машины сохраняют оригинальную графику; в правом верхнем углу рисуется цифра тира (★ для мастер-тира). У иконок предметов тот же значок.
- Тиры образуют цепочку улучшений: работают планировщик улучшений и быстрая замена.

## Настройки

| Настройка | По умолчанию |
| --- | --- |
| Количество тиров | 5 |
| Машин предыдущего тира на улучшение | 5 |
| Рост бонусов | линейно / сложно |
| Бонус скорости за тир | 100% |
| Рост потребления энергии за тир | 100% |
| Доп. слоты модулей за тир | 1 |
| Загрязнение растёт вместе с энергией | вкл |
| Сборщики / печи / буры / морские насосы / лаборатории | вкл / вкл / вкл / вкл / выкл |
| Исключённые машины (через запятую) | пусто |
| Значок тира: показ / размер / только alt (карта, runtime) | вкл / 0.6 / выкл |

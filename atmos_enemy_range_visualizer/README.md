# Atmos Enemy Range Visualizer

Factorio **2.1** mod that draws attack-range circles around **enemy** worms, turrets, and artillery — similar in spirit to [Gun Range Visualizer](https://mods.factorio.com/mod/gun-range-visualizer), but for hostile defenses.

## Features

- Toggle via shortcut bar or **Ctrl+Shift+R**
- Settings panel: **Ctrl+Shift+E** or the worm button (gear badge) in the mod button bar (enable, style, lines, category filters)
- Styles: **filled**, **outline**, **filled + outline**
- Separate colors for worms / ammo / electric / fluid / artillery (Mod settings)
- Multiplayer-friendly: each player sees only their own overlays

## Recommended companion

Install **[Gun Range Visualizer](https://mods.factorio.com/mod/gun-range-visualizer)** for your own gun/vehicle range. This mod lists it as a recommended dependency (`+ gun-range-visualizer`).

## Covered enemy types

| Category | Entity types |
| --- | --- |
| Worms | `turret` (small/medium/big/behemoth worms, modded worms) |
| Ammo turrets | `ammo-turret` |
| Electric turrets | `electric-turret` |
| Fluid turrets | `fluid-turret` |
| Artillery | `artillery-turret` |

Only entities on forces that are **enemies** of the player are shown.

# Atmos Enemy Range Visualizer

Мод для Factorio **2.1**: рисует круги дальности атаки вокруг **вражеских** червей, турелей и артиллерии — по аналогии с [Gun Range Visualizer](https://mods.factorio.com/mod/gun-range-visualizer), но для вражеских укреплений.

## Возможности

- Переключение шорткатом или **Ctrl+Shift+R**
- Панель: **Ctrl+Shift+E** или кнопка с червём (шестерёнка) в панели кнопок модов (вкл/выкл, стиль, линии, фильтры категорий)
- Стили: **заливка**, **контур**, **заливка + контур**
- Отдельные цвета для червей / стрелковых / электро / жидкостных / артиллерии (настройки мода)
- В мультиплеере каждый игрок видит только свои оверлеи

## Рекомендуемый компаньон

Поставьте **[Gun Range Visualizer](https://mods.factorio.com/mod/gun-range-visualizer)** для дальности своего оружия/техники. В `info.json` он указан как recommended (`+ gun-range-visualizer`).

## Покрытые типы

| Категория | Типы сущностей |
| --- | --- |
| Черви | `turret` |
| Стрелковые турели | `ammo-turret` |
| Электротурели | `electric-turret` |
| Жидкостные турели | `fluid-turret` |
| Артиллерия | `artillery-turret` |

Показываются только сущности сил, враждебных игроку.

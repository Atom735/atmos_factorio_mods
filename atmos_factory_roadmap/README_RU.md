# Atmos Factory Roadmap

Интерактивный гид по развитию для Factorio 2.1. Только интерфейс: никаких новых предметов, рецептов и объектов.

Нажмите кнопку с лабораторией в левом верхнем углу, чтобы открыть окно «Что строить дальше».

- 12 этапов: стартовый комплект, электричество и лаба, колонны печей, мини-молл, красные/зелёные колбы, улучшение электростанции, военные колбы и сталь, нефть, химические, производственные колбы, колбы использования, запуск ракеты.
- Текущий этап — первый с невыполненными целями. Цели проверяют построенные объекты, изученные технологии и общее количество произведённых предметов вашей команды.
- Для каждого этапа: список целей с прогресс-барами, описание и золотые соотношения (энергия, печи на ленту, соотношения автоматов колб, крекинг нефти и т.д.).
- Стрелками можно листать этапы; кнопка сброса возвращает к слежению за текущим этапом.
- При прохождении этапа команда получает сообщение в чат.

Цели с отсутствующими прототипами (удалёнными другими модами) пропускаются.
